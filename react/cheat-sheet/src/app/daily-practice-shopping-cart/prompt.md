## Shopping Cart


### Step 1
Create a React app that fetches products from an endpoint and displays them


### Step 2
Enable adding products to a cart, and removing them, with quantity controls (increment/decrement)

The cart contents should update immediately to reflect changes

### Step 3
Display a running subtotal per cart item and a cart total

Enable filtering the product list by category

### Step 3 1/2
Enable sorting the product list
Should be able to sort by
    - Price ascending/descending
    - Name ascending/descending

### Step 4
Using flex, display the products as rows and columns of product cards, that adjusts how many products there are in a row based on width

### Step 5
Save your progress
